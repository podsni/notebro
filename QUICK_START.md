**Version**: 1.1.0 | **Date**: June 9, 2026 | **Status**: ✅ Production Ready

## ⚡ What's New

### 1. Quick Capture (`Ctrl+Shift+Space`)
Press the shortcut anywhere to instantly create a note. Perfect for capturing fleeting thoughts!

### 2. Templates (`Ctrl+Shift+T`)
Choose from 8 professional templates:
- **Meeting Notes** - Structured meeting documentation
- **Daily Journal** - Morning/evening reflection
- **Todo List** - Prioritized tasks
- **Project Planning** - Full project structure
- **Study Notes** - Learning template
- **Brainstorming** - Idea capture
- **Recipe** - Cooking template
- **Blank** - Start fresh

### 3. Better Settings
- **5 organized tabs**: General, Editor, Appearance, Data, Advanced
- **Search bar**: Find settings instantly
- **Export/Import**: Backup your preferences as JSON
- **Reset**: One-click return to defaults

---

## 🎯 Try These Now

1. **Quick Capture**
   ```
   Ctrl+Shift+Space → Type → Ctrl+Enter → Done!
   ```

2. **Use a Template**
   ```
   Ctrl+Shift+T → Choose "Meeting Notes" → Start writing!
   ```

3. **Customize Settings**
   ```
   Open Settings → Appearance → Pick your theme
   ```

4. **Backup Preferences**
   ```
   Settings → Data → Export Settings → Save JSON
   ```
